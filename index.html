📋 Overview

The omp-alibaba-maas software brings advanced artificial intelligence to your computer. It connects your system to the Alibaba Cloud Bailian platform. This allows you to use smart chat models like Qwen3, GLM-5.2, and DeepSeek. You can also create images and video clips using advanced tools like wan2.7 and HappyHorse. Use simple slash commands to control these features.

⚙️ System Requirements

Ensure your computer meets these basic needs before you start:

  • Operating System: Windows 10 or Windows 11.
  • Memory: At least 8GB of RAM.
  • Processor: Modern dual-core CPU or better.
  • Storage: 500MB of free disk space.
  • Internet: Active connection for cloud model access.

📥 Installing the Software

Follow these steps to set up the software on your Windows machine:

  1. Visit the official download page to locate the latest version.
  2. Look for the release section on that page.
  3. Select the Windows installer file.
  4. Save the file to your computer.
  5. Double-click the downloaded file to start the installation.
  6. Follow the instructions on the screen.
  7. Click Finish when the process ends.

🛠️ First Time Setup

Open the application after the installation finishes. You need an API key from your Alibaba Cloud account to link the services. Copy your key from the account dashboard and paste it into the settings menu of the app. Save your changes to enable the chat and image tools.

💬 Using the Command Interface

The software responds to specific commands. Type these into the main input box:

  • /chat: Starts a conversation with the selected AI model.
  • /img: Requests an image generation based on your text.
  • /video: Generates a short video clip.
  • /video-i2v: Transforms an existing image into a video.

🛡️ Troubleshooting

If the program fails to start, restart your computer. If the AI does not respond, check your internet connection and ensure your API key remains valid in the settings menu. Clear the app cache if you experience slow performance while generating images or large files.
